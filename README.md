# Лабораторна робота №4. Служби DNS та NAT. Підходи до траблшутінгу мережі

**Дисципліна:** Тестування та контроль якості (QA) вбудованих систем
**Виконала:** Павлюк В.О., група ІА-32 (КПІ ім. Ігоря Сікорського, ФІОТ)

## Мережне оточення

| Вузол | Налаштування |
|---|---|
| PC1 (server) | enp0s8: 10.0.0.1/8 (статична), DHCP-сервер; enp0s3: 10.0.2.15 (NAT VirtualBox); ip_forward = 1; `MASQUERADE -s 10.0.0.0/8 -o enp0s3` |
| PC2 (client) | enp0s3: 10.0.0.10/8 (DHCP), шлюз 10.0.0.1, DNS 192.168.0.1, 8.8.8.8 |

## Файли

- `ЛР4_Павлюк_ІА-32.docx` / `.pdf`: звіт
